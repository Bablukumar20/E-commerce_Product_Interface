# Shoply — E-Commerce Product Interface

**Task 5 (Advanced) – E-Commerce Product Interface**

A modern, responsive e-commerce frontend built with vanilla HTML, CSS and advanced JavaScript.

## Requirements covered

1. Build product listing pages.
2. Design product cards and responsive layouts.
3. Implement product search and filtering.
4. Create a shopping cart interface.
5. Optimize UX and responsiveness.

## Key features

- Product catalog with 9 sample products
- Search by product name/category
- Category filtering
- Price range filter
- Minimum rating filter
- Deals-only filter
- Sorting: featured, price, rating and name
- Product detail modal
- Wishlist toggle
- Shopping cart drawer
- Increase/decrease cart quantities
- Remove items
- Persistent cart and wishlist using Local Storage
- Responsive desktop/tablet/mobile layouts
- Keyboard shortcut: `Ctrl + K` focuses search
- Toast notifications
- Accessible labels and buttons

## Technology

- HTML5
- CSS3
- JavaScript ES6+
- DOM manipulation
- Local Storage
- Responsive CSS Grid/Flexbox

## How to run in VS Code

### Recommended: Live Server

1. Extract the ZIP.
2. Open `ecommerce-product-interface` in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html`.
5. Choose **Open with Live Server**.

### Without Live Server

You can also double-click `index.html` and open it in a browser.

Product images are loaded from Unsplash URLs, so an internet connection is recommended for the full visual experience.

## Important

This is a **frontend-only demo**. The checkout button is intentionally a demo action. A real payment flow would require a backend and a payment provider such as Razorpay/Stripe.
